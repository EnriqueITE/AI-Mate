# AI Mate 1.0.23 — store release notes

## Español

- Reescribe el texto seleccionado con seis estilos: Parafrasear, Formal, Directo, Cercano, Más breve y Más detallado.
- Revisa el original y el resultado antes de reemplazar la selección. Puedes regenerar, copiar, cancelar o deshacer el cambio recuperando el formato original.
- La reescritura envía únicamente la selección, los destinos de sus enlaces y las instrucciones de esa acción. Rechaza selecciones incompatibles y evita reemplazar texto si el correo ha cambiado.
- GPT-6 Luna pasa a ser el modelo inicial en instalaciones nuevas y se añade GPT-6.1 Terra. Las instalaciones existentes conservan su modelo y sus límites.
- Corregido el tamaño del panel de redacción, con acceso visible a Ajustes y Generar respuesta. Se mantienen Mejorar borrador, Resumir y Deshacer.
- Actualizaciones de seguridad y privacidad: sanitizador HTML actualizado, validación de mensajes internos y exclusión de adjuntos al preparar resúmenes.

La interfaz continúa en inglés. Requiere Thunderbird 115 o posterior y una clave propia de la API de OpenAI.

## English

- Rewrite selected text in six styles: Paraphrase, Formal, Direct, Friendly, Shorter, and More detailed.
- Compare the original and preview before replacing your selection. Regenerate, copy, cancel, or undo the change to restore the original formatting.
- Rewriting sends only the selected text, its link destinations, and instructions for that action. Unsupported selections are rejected, and replacement is blocked if the email has changed.
- GPT-6 Luna is now the default for new installations, and GPT-6.1 Terra is available. Existing installations keep their selected model and limits.
- Fixed the compose panel size and kept Settings and Generate Reply accessible. Improve Draft, Summarize, and Undo remain available.
- Security and privacy improvements include an updated HTML sanitizer, internal message validation, and attachment exclusions when preparing summaries.

The interface remains in English. Requires Thunderbird 115 or newer and your own OpenAI API key.
